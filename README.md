# Ali Towaiji Portfolio
Personal portfolio website with a 3D interactive experience.

Live version: [towaiji.netlify.app](https://towaiji.netlify.app/)

## Tech Stack

- Next.js
- React
- React-three-fiber
- DREI
- GSAP
- Zustand
- Tailwind

## Preview
Run the app locally:

```bash
npm install
npm run dev
```
